# Security policy

## Reporting a vulnerability

Report it privately, through GitHub's
[security advisory form](https://github.com/mmedum/google-drive-mcp/security/advisories/new)
on this repository. Do not open a public issue.

Include what an attacker could do, how to reproduce it, and the version
(`google-drive-mcp --version`, a release tag or a commit). Never include
a real file's id, link, name or content, an account address or a token;
a synthetic reproduction is enough.

## Supported version

Only the latest release receives fixes.

## Response

We acknowledge a report within **7 days**.

[`docs/security.md`](docs/security.md) is the threat model. It says what
counts as a vulnerability here and what does not.
